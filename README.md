# clinical-protocol-skill
> 临床研究方案设计全流程 Agent Skill

## 📌 简介
本仓库为面向临床研究的AI技能包，深度融合 **ICH M11国际协调模板、SPIRIT 2013国际标准、北京大学临床研究撰写指南、华西医院院内立项规范**，构建「国际注册 + 国内IIT」双轨制模板体系，覆盖从需求采集 → 方案撰写 → 配套文档 → 合规核查 → 伦理应答的全链路支持。

✅ 覆盖研究类型：
- IIT单中心/多中心研究
- RCT随机对照试验（优效/非劣效/等效）
- 观察性研究：队列、病例对照、横断面、回顾性
- 诊断试验、真实世界研究
- 国际多中心注册临床试验

✅ 双轨制模板体系：
- **国际注册版**：对齐 ICH M11 + ICH E9(R1) 被估量框架 + SPIRIT 33项
- **国内IIT版**：融合北大/华西/中山规范，适配医院伦理与科技处立项

✅ 可输出配套文档：
- 临床研究方案初稿（按场景自动匹配模板）
- ICF知情同意书（成人/弱势群体版本）
- SAP统计分析计划
- CRF病例报告表设计模板
- 伦理审查申请函 + 风险评估表
- 伦理意见逐条应答函
- 方案修正案 + 修订记录
- 研究进度甘特图 + 经费预算科目表

## 🖥️ 前端交互界面
仓库内置单文件向导式前端（中英双语）：`web/index.html`

五步向导流程，与 SKILL.md 模板体系一一对应：
1. **研究类型**：干预性 / 观察性 / 诊断试验·真实世界 / 上市后研究（PMR/PMC）
2. **研究设计**：按类型动态加载 RCT、队列、病例对照、PMR/PMC 等设计方案
3. **基础信息**：项目名称、适应症、干预/对照、中心数、样本量、入排标准
4. **配套文档**：ICF、CRF、SAP、伦理申请函、修正案、应答函、预算表、SPIRIT/E6(R3) 核查清单
5. **方案预览与导出**：自动汇总生成方案框架 + 合规核查清单，一键导出**全套 Word 方案（.docx）**

使用方式：浏览器直接打开 `web/index.html` 即可，零构建、无后端依赖。

**导出能力说明**
- 默认输出真正的 `.docx`（docx.js 渲染，A4 版式、宋体正文/黑体标题、真表格边框、页脚页码、封面独立成页）
- 内容构成：封面 + 方案正文（按研究类型匹配模板）+ 已勾选的配套文档全文 + 合规核查清单附录，每份文档独立分页
- 未填写的信息以红色【待补充】标注，便于团队接力完善
- 离线或 CDN 不可达时，自动降级导出 Word HTML（`.doc`），Word/WPS 同样可直接打开

## ⚠️ 重要免责声明
本技能所有输出仅为**学术写作模板与辅助框架**，不替代统计师、伦理委员会、药监机构的正式评审；所有文稿提交伦理/立项前，必须由研究团队、统计师、PI共同审核确认，符合《研究者发起临床研究管理办法》、赫尔辛基宣言及GCP相关要求。
